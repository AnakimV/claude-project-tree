# Дерево проекта — мод для Claude Code

Панель рядом с чатом, где видно, что в проекте сделано, что открыто и что решили. Удобно, когда возвращаешься к проекту и не помнишь, на чём остановился. Подходит не только для программирования.

*A Claude Code mod: a project tree pane beside the chat — branches and tasks, open questions, ideas, findings, and a history of key steps. The interface is in Russian.*

## Что внутри

- **Схема** — ветки (направления, фичи) и задачи с подзадачами, соединённые линиями. На выбранной задаче прямо на карточке: «✓ Готово», «↪ Ответить», «● В работу» / «⏸ Отложить», «✕».
- **Вопросы, Идеи, Находки** — всё, что ещё не задача. Здесь решаешь: «→ В работу» (станет задачей в схеме), «↪ Ответить» или «✕ Не нужно». У решений варианты выбираются кнопками.
- **История** — важные шаги по дням: закрытые задачи, принятые решения, убранное с причиной, шаги, которые отмечает Claude. Закрытое можно вернуть.
- **Привязка к сообщению** — каждый узел помнит сообщение в чате, из-за которого появился.
- **«↪ Ответить»** — вставляет задачу в поле ввода, дальше ответ можно надиктовать; Claude получает полный контекст задачи.
- **Claude ведёт дерево сам** — по ходу работы добавляет находки, вопросы и идеи, записывает важные шаги в историю. Смену статуса он только предлагает, ты подтверждаешь на карточке.

Дерево хранится в проекте, в файле `.claude/project-tree.json`. У каждого проекта своё.

## Установка

В сессии Claude Code в терминале:

```
/plugin install project-tree --marketplace AnakimV/claude-project-tree
```

Из командной строки:

```
claude plugin install project-tree --marketplace AnakimV/claude-project-tree
```

В десктопном приложении, где `/plugin` не работает: нажми **+** рядом с полем ввода → **Plugins** → **Add marketplace**, введи `AnakimV/claude-project-tree`, затем **Add plugin**.

После установки панель «Дерево проекта» открывается сама; если нет — введи `/tree`.

## Быстрый ввод

В поле внизу панели или командой `/tree`:

```
# ветка   - задача   ? вопрос   ! решение   * идея   > находка   ~ заметка
```
